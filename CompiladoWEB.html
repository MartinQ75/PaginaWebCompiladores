Fases de un Compilador

El compilador es un programa informatico cuya función principal es traducir código fuente escrito en un lenguaje de programación legible para los humanos a un código ejecutable que puede ser leido por la computadora. Un compilador debe pasar por seis etapas para llegar al código objetivo.

Análisis Léxico

En la fase del análisis léxico se escanea el código fuente para convertirlo en unidades más pequeñas llamadas "tokens". Estos tokens representan las partes más básicas y significativas del código.

Funciones principales

- Eliminar espacios y comentarios.
- Detectar identificadores, palabras reservadas y operadores.
- Generar tokens para el análisis sintáctico.

int numero = 10;

El analizador léxico separa esta línea en tokens como: int, numero, =, 10 y ;

Análisis Sintáctico

La función principal del análisis sintáctico es analizar la estructura la estructura gramatical del código fuente y construir un arbol de sintaxis abstracto (AST);

Objetivo

Detectar errores de sintaxis como paréntesis faltantes, instrucciones incompletas o estructuras mal escritas.

if(x > 5){ printf("Hola"); }

El compilador verifica que la estructura del if sea válida.

Árbol Sintáctico

El árbol sintáctico es una representación jerarquica que elimina el "ruido" (paréntesis, comas, llaves) y se queda solo la lógica. Cada nodo del árbol representa operaciones, expresiones o instrucciones.

Importancia

Permite organizar las expresiones matemáticas y estructuras del programa para facilitar el análisis semántico y la generación de código.

(+) / \ (5) (*) / \ (3) (2)

Análisis Semántico

El objetivo del análisis semántico es verificar la coherencia y el significado del código fuente. El análisis semántico se preocupa de las reglas y significados especificos del del lenguaje de programación.

Ejemplo

int edad = "hola";

Aunque la sintaxis puede ser correcta, existe un error semántico porque una cadena de texto no puede almacenarse en un entero.

Generación de Código Intermedio

Después del análisis semántico, el compilador genera una representación del programa a un nivel de abstracción que está entre el código fuente y el código de máquina especifico de la arquitectura, este código intermedio es una forma de código que es independiente a la plataforma.

Objetivo

Facilitar la optimización y permitir compatibilidad entre distintos procesadores.

t1 = a + b t2 = t1 * c

Optimización de Código intermedio

Su objetivo es mejorar la eficiencia del programa final sin cambiar su lógica. Busca generar un ejecutable más rápido, que requiera menos recursos de ya sea de procesamiento o memoria.

Técnicas comunes

- Eliminación de código muerto.
- Reducción de operaciones repetidas.
- Optimización de ciclos.

Generación de Código Objetivo

En este proceso el compilador procede a generar código especifico para la arquitectura de la máquina en la que se ejecutara el programa compilado.

Resultado final

El resultado puede ser un archivo ejecutable que el sistema operativo pueda ejecutar directamente.

MOV AX, 5 ADD AX, 3
